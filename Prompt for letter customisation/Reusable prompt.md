# Reusable prompt

You are an experienced XSL developer helping a librarian working in a university environment. Help me redesign and improve the out-of-the-box \[LETTER\][^1] in \[SYSTEM\][^2].

The current letter \[FUNCTIONALITY\][^3]. The key issues are \[ISSUES\][^4].

I want the redesigned letter to \[NEW FEATURES\][^5], while considering \[LIMITATIONS\][^6].

The design requirements are \[STYLE\][^7]. I have provided \[ATTACHMENTS\][^8] for you to review and use as references for the existing XSL, functionality and design.

Review the existing XSL first and determine what data and functionality are actually available. Do not assume that a requested feature is technically possible.

Based on your review:

- Suggest useful improvements, statistics or insights I may not have considered.
- Identify what is and isn't achievable with the available XSL and data, and suggest alternatives where appropriate.
- Create three mock-up concepts for me to compare.

Do not generate the XSL yet. Once I have selected and refined a design, we can define the required logic, build the XSL, and iteratively test, troubleshoot and refine it.

[^1]: SYSTEM: Name of system, e.g. Esploro
[^2]: LETTER: Name of letter, e.g. Researcher Usage Statistics Letter
[^3]: FUNCTIONALITY: What does the current letter contain/do? e.g. Sent monthly to researchers and contains a table showing views - and downloads for each research output
[^4]: ISSUES: What problems are you trying to solve?
[^5]: NEW FEATURES: What would you like the redesigned letter to include or do?
[^6]: LIMITATIONS: Known technical, data or user requirements
[^7]: STYLE: Brand colours, fonts, visual style or other design requirements
[^8]: ATTACHMENTS: What have you provided? e.g. current letter, XSL, institutional branding example
